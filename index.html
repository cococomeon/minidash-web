三分钟走完的路

步骤你要做的页面会做什么
1拖进 CSV，或点「用示例数据试试」自适应逗号 / 分号 / Tab / 竖线分隔符，吃掉 BOM 和 CRLF，正确处理引号里的逗号
2看一眼列映射，不对就手动改自动认出日期 / 渠道 / 订单数 / 销售额 / 退款额（含中英文别名），认错可以下拉纠正
3点「下载 PNG 卡片」或「复制文字日报」在浏览器里把卡片画进 canvas，导出 1080×1440 PNG；文字版直接进剪贴板

整条链路没有任何网络请求：文件通过浏览器的 FileReader 读进内存，计算用 JavaScript 完成，图片用 canvas 的 toBlob 生成。你把浏览器关掉，数据就没了。

它到底算哪几个数

免费版固定这五类指标，口径写在下面，不玩模糊：

指标口径
本周销售额以数据里最后一天为终点，往前取 7 个自然日，销售额求和（缺失的日子按 0 计）
订单数同一 7 天窗口内的订单数求和；客单价 = 销售额 / 订单数
退款率窗口内退款额合计 / 销售额合计
单日最高退款率窗口内每一天单独算 退款额 / 当天销售额，取最大值并标出是哪一天
环比本窗口销售额 vs 紧邻的前一个 7 天窗口销售额

三条预警线

触发条件你会看到
7 天退款率 > 5%红色警报，附退款额与销售额
某单日退款率 > 10%红色警报，点名是哪一天，提醒核对退款明细
销售额环比跌幅 > 30%红色警报，附上期金额

三条都没触发时，页面会明确告诉你「指标在健康区间」，而不是空着让你自己猜。

列名不用改，它自己认

角色能认的表头必需

销售额revenue / sales / amount / gmv / 销售额 / 金额 / 营收 / 收入 / 成交额是
订单数orders / order / order_count / 订单数 / 订单量 / 单量 / 销量否
退款额refunds / refund / refund_amount / 退款额 / 退款金额 / 退款否

金额列能吃掉 ¥1,234.56、$1,234、1.234,56、(1,234) 这些写法；日期能认 2026-11-01、2026/11/01、2026年11月1日、20261101、11/01/2026。

常见问题

数据真的不会上传吗？

真的。页面是纯静态 HTML + CSS + JS，没有任何后端接口、没有第三方统计脚本、没有 CDN。你可以打开浏览器开发者工具的 Network 面板，上传文件后不会出现新的请求。

支持 Excel（.xlsx）吗？

目前不支持，只支持 CSV。Excel 的 .xlsx 是一个 zip 压缩包，要在浏览器里零依赖解开并解析 XML 的成本很高，所以本工具选择不假装支持：检测到 Excel 文件会直接告诉你「请另存为 CSV」，并给出步骤。详见 excel.html。

CSV 需要什么格式？

第一行是表头，之后每行一条记录，至少要有「日期」和「销售额」两类列。逗号 / 分号 / Tab / 竖线分隔都能自动识别，带 BOM 的 UTF-8、GBK、CRLF 换行也都能读。

导出的 PNG 能直接用吗？

能。PNG 固定 1080×1440（竖版 3:4），适合微信、朋友圈、小红书和截图贴进周报。卡片只画了文字、矩形和渐变，没有外部字体和图片，导出不会缺图。

会保存我的数据吗？

不会。没有登录、没有数据库、没有 localStorage 缓存业务数据。刷新页面即清空。

能算利润、广告费、分渠道吗？

免费版不算。它只做销售额 / 订单 / 退款率 / 环比 / 单日异常这几类通用指标。要按自己的口径做（含毛利、扣广告费、分渠道拆解、自动发群），那属于定制版。

要按你自己的口径来一份？

免费版固定算这几类指标：销售额、订单数、退款率、环比、单日异常。如果你的日报还要分渠道、算毛利、扣广告费、自动发到群里——那是定制版干的活，把一份脱敏后的 CSV 给我，我按你的口径做一个。
